# Xinya Li — Personal Website

Multi-language personal portfolio website (EN / FR / 中文 / 日本語).

## Deploy to GitHub Pages

1. Push this repo to `main` branch of `Xinya-Li-mylife/My-personal-website`
2. Go to **Settings → Pages → Source → Deploy from branch → main / (root)**
3. Your site will be live at `https://xinya-li-mylife.github.io/My-personal-website/`

## Structure

```
index.html   — main page (all sections)
style.css    — aesthetic toothpaste palette + McKinsey-clean layout
i18n.js      — translations: EN, FR, ZH, JA
main.js      — scroll animations, nav, language switcher
assets/      — profile photo + CV PDF
```
